# Machine Learning Labs

Репозиторий с лабораторными работами по машинному обучению на Python.

## Содержание

- `LR_1` — регрессия: линейная регрессия, Random Forest, XGBoost, feature engineering, анализ важности признаков.
- `LR_2` — классификация: Logistic Regression, SVM, KNN, Decision Tree, Random Forest, Gradient Boosting, сравнение метрик и моделей.
- `LR_3` — продвинутая классификация: предобработка данных, feature engineering, отбор и преобразование признаков, CatBoost, настройка гиперпараметров, оценка качества моделей.
- `LR_4` — Bayesian Networks: построение структуры сети, оценка параметров, анализ CPT, inference, визуализация и сравнение с baseline.

## Технологии

Python, Jupyter Notebook, NumPy, Pandas, Matplotlib, Seaborn, scikit-learn, XGBoost, CatBoost, Optuna, pgmpy.

## Примечание

Каждая лабораторная работа находится в отдельной папке и содержит ноутбук с кодом, результатами и визуализациями.
